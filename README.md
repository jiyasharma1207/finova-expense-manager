# Finova – Smart Expense & Subscription Manager

Finova is a modern and responsive personal finance dashboard built with React.js.

It helps users track their income, expenses, monthly budget, spending categories, and recurring subscriptions in one simple interface.

The project uses browser localStorage to save transactions and subscriptions, so data remains available even after refreshing the page.

## 📌 Features

- 📊 Financial dashboard with summary cards
- 💰 Track income and expenses
- ➕ Add new transactions
- 🗑️ Delete transactions
- 🔍 Search transactions
- 💳 Track recurring subscriptions
- ➕ Add new subscriptions
- 🗑️ Delete subscriptions
- 📅 View upcoming subscription payments
- 📈 Monthly budget tracking
- 🧾 Expense category analysis
- 💾 Data persistence using localStorage
- 📱 Responsive design for desktop, tablet, and mobile
- 🔔 Notification panel
- 🧭 Sidebar navigation
